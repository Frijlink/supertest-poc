# supertest-poc
Small POC using supertest and vitest

## How to run
- Add `.env` to directory
- Add the necessary variables in `.env`
| Variable         | Content                |
|------------------|------------------------|
| API_URL          | https://api.trello.com |
| TRELLO_API_KEY   |                        |
| TRELLO_API_TOKEN |                        |
- Run `npm i`
- Run `npm test`
